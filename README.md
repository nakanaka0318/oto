# OTO STAGE 🎵

プロセカ風のブラウザ音ゲーです。インストール不要・ビルド不要で、PC / スマホのブラウザで遊べます。

## 遊べるもの

### 1. AI作曲の収録曲 3曲 (各 HARD / EXPERT / MASTER)
アプリ内の作曲エンジン (`js/composer.js`) がコード進行とシード値からメロディ・ドラム・ベース・パッド・アルペジオを生成し、
自作シンセサイザーでその場で演奏します（外部の音源素材は使っていない完全オリジナル曲です）。
譜面も作曲データ（メロディの音程・長さ、ドラム、シンバル）から難易度別に自動生成されます。

| 曲 | BPM | ジャンル | HARD | EXPERT | MASTER |
|---|---|---|---|---|---|
| Neon Pulse | 140 | シンセポップ | 16 | 19 | 30 |
| Starlight Runner | 172 | ドラムンベース (王道進行) | 17 | 24 | 32 |
| Crimson Overdrive | 186 | ハードコア | 17 | 26 | 37 |

### 2. 好きな曲を取り込んで譜面を作る
「＋ 曲を追加」から:
- **音声 / 動画ファイル** (MP3, WAV, OGG, M4A, MP4 など) … 音を解析して BPM・1拍目・リズムを検出し、3難易度の譜面を自動生成します。
- **YouTube の URL** … 公式の埋め込みプレイヤーで動画を背景に再生します。YouTube の音声は解析できないため、BPM（TAP計測できます）と1拍目の位置から譜面を生成します。

自動生成した譜面は **譜面エディタ** で自由に修正できます。

## 操作

| | タッチ / マウス | キーボード |
|---|---|---|
| タップ | ノーツのレーンをタップ | `S` `D` `F` `J` `K` `L` (設定で変更可) |
| フリック (ピンク) | タップしてはらう | 対応キーを押す |
| ロング (緑) | 押したまま、スライドに合わせて指を動かす | 押しっぱなし |
| 終点フリック | ロングの最後ではらう / 離す | ロング終点でキーを離す |
| クリティカル (金) | 通常と同じ (演出が豪華) | |
| 一時停止 | 右上の ❚❚ | `Esc` |

判定: PERFECT ±42ms / GREAT ±83ms / GOOD ±108ms / BAD ±125ms。GOOD 以下でコンボが切れます。

設定でノーツ速度・オフセット・音量・ノーツサイズ・タッチ判定の広さ・キー配置・オートプレイなどを変更できます。

## 🎧 音ズレ自動補正

選曲画面右上の「🎧 音ズレ補正」から。

1. プレイ時と同じイヤホン/スピーカーで、クリック音に合わせてパッドを **16回** タップ
2. 「音が実際に聞こえた時刻」と「タップした時刻」のズレを測り、外れ値を除いた平均をオフセットとして **自動で適用**
   (Bluetooth イヤホンの遅延・端末の出力遅延・タッチ遅延・本人のクセをまとめて吸収)
3. さらに **プレイするたびに** タイミングの傾向 (早め/遅め) を計測し、オフセットを少しずつ自動調整します。
   リザルト画面にタイミング分布のグラフと補正量が表示され、「元に戻す」もできます。
   YouTube はプレイヤー側の遅延が別にあるため、別枠 (YouTube 追加補正) で学習します。

## 📱 スマホで遊びやすくする工夫

- プレイ開始時に **全画面 + 横向き固定** (Android Chrome)。iPhone は Safari の共有 →「ホーム画面に追加」で全画面アプリとして起動できます
- **タッチ判定を広めに** (設定で 狭い/標準/広い)。指の真下のノーツを優先するので隣のノーツを誤爆しにくい
- フリック判定の距離を画面サイズに合わせて短く
- ノッチ / ホームバー (セーフエリア) を避けて HUD を配置
- プレイ中の画面スリープ防止、ピンチズーム・ダブルタップズーム・引っ張って更新を無効化
- iPhone のマナーモードでも音が鳴るように設定
- タップ時の振動 (Android)、**軽量モード** (解像度と光の演出を抑えてカクつきを軽減)

## 譜面エディタ

- ツール: タップ(1) / フリック(2) / ロング(3, ドラッグで終点、左右に動かすとスライド) / 消去(4) / 移動(5)
- クリティカル(C)、ノーツ幅 1〜12、フリック方向、ロング終点フリック
- スナップ 4〜32分、拡大縮小、波形表示、BPM / 1拍目の調整、TAPでBPM計測
- **リアルタイム録音**: 再生しながら S D F J K L を叩くとノーツが置かれる（長押しでロング）
- 自動生成・他難易度からコピー・Undo (Ctrl+Z)・保存 (Ctrl+S)・JSON 書き出し/読み込み
- 「ここからテスト」で現在位置からテストプレイ

AI曲の譜面も「譜面をコピーして編集」で自分用に改造できます。

## 起動方法

YouTube 機能を使う場合は http(s) で配信する必要があります（`file://` だと YouTube が埋め込みを拒否します）。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で このブランチ / ルート を指定するだけで動きます。

## データの保存先

取り込んだ曲・譜面はブラウザの IndexedDB、設定とハイスコアは localStorage に保存されます（サーバーには送信されません）。
著作権のある楽曲は個人で楽しむ範囲でご利用ください。
